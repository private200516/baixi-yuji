## 坐标来源与可重复检查

1. 双枝庙与龙宫陈氏宗祠保留百科的固定版本 URL、原始度分秒表示和页面十进制度。两者均按 `[经度, 纬度]` 存储为 WGS84；计算 `度 + 分/60 + 秒/3600` 后与十进制度差小于 `0.00000005°`。仅做表示换算，没有 GCJ-02、BD-09 偏移转换。固定版本分别为 `85668020`、`89181774`。
2. 申坎头水库来自保留的原始 Overpass JSON 中 `way/1210271570` 的 `center` 字段。这是 Overpass `out center` 返回的水域包围盒中心，不是测量点，也不保证落在可通行地面。OSM 几何未下载成功，因此没有以伪造边界代替原始对象。
3. Overpass 查询在五个既有村落代表点周边 1 km 搜索有名称对象。该半径只用于检索，**不是村界，也不构成 POI 所属关系证据**。查询得到的公交站、停车场等没有自动导入景点或运营数据。
4. 原始结果使用 ODbL-1.0，并保留 [OpenStreetMap 署名](https://www.openstreetmap.org/copyright)。获取日为 2026-10-19，但该镜像返回 `2026-07-28T02:16:18Z` 快照；不能称为十月实地更新。
5. 核验清单与 SHA-256 见 `data/geography/poi-evidence/verification.json`；请求文件、原始结果及来源记录位于同目录。政府 PDF 的相关页已渲染检查文字、照片说明和地图对应，未从无地理注册地图估算坐标。

## 未纳入的候选与不能完成的验收

- **许家山旧采石场：** 原始 OSM 有 `way/1347061000`，名为“旧采石场”。[中国旅游报《许家山“石头记”》](https://www.ctnews.com.cn/paper/content/202609/01/content_114961.html)描述了村内采石遗址，但现有文字没有明确位置、范围或唯一性，不能证明与该 OSM 对象是同一处。它没有进入正式景点目录；不能仅凭“同村＋同类”给它已核验坐标。
- **箬岙规划图：** 规划简本有保护对象标注、比例尺和指北针，却没有足够地理注册控制点或明确坐标格网。资料可证明建筑名称与归属，不能据此猜经纬度。需要规划方提供带坐标数据、明确地理注册文件，或独立可核验点位来源。
- **同名/近邻误用：** 余姚梨洲箬岙不是本项目的一市镇箬岙；双枝庙公交站也不是双枝庙建筑本身。均未借用这些位置来补空值。
- **多点地图验收：** 五村均可在同源文字列表浏览多条介绍，但每村现阶段最多一条已核对地图资料点。因此“一个古村多个真实景点同时落图”的实际截图仍待补充独立位置证据，不能用挪动坐标或测试数据替代。
- **照片与开放状态：** 首轮没有可确认复用许可的地点照片，故 `image: null`。历史建筑和水库的参观范围、开放安排均未核实；当前简介不包含到访许可承诺。
