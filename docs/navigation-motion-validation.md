# 古镇导航过渡验收 · 2.0.1

2026-10-09，独立 Edge 浏览器视口验收。保留2.0各页的最终导航位置、尺寸和皮肤，修复切换期间的突变。

## 修复与实测

普通页导航由网格定位，古镇页由底部定位；原先换布局会让同一个导航DOM立即跳位。古镇样式曾随懒加载组件到达，首次打开还可能产生延迟跳变。现在样式静态加载，布局测量槽保持目标尺寸，内部导航按480ms连续插值；凹槽和圆座与同一帧几何同步，图标不缩放。颜色也按同样的缓动过渡。

| 视口 | 原跳变 | 修复后的连续过程 |
| --- | --- | --- |
| 390×844 | 单帧向下90px | 31个位置，最大单帧8.54px |
| 430×932 | 单帧向下178px | 28个位置，最大单帧16.80px |
| 320×568 | 高度341px直接变285px | 28个高度值，最大单帧5.22px |

上述采样帧数与单帧步长依赖设备帧率；自动化断言关注连续中间值、最大步长占比、末态稳定及对齐，而非固定帧数。

## 验证范围

`pnpm test:navigation-motion` 共11项通过，包含320/390/430手机视口、320大字号、1440×900桌面缩放预览、首次进入与返回、连续中断切换、系统及应用减少动效。每帧圆座与凹槽位置一致，保留同一导航DOM，末态图标居中误差不足0.024px，无未捕获脚本错误。

补充检查：动画中桌面缩放从0.84变为0.72后正确落位；动画中开启系统减少动效，两帧后立即到达终点，之后保持静止。19项单元/数据检查、320/390大字号八页面回归、已有快速导航和减少动效回归、生产子路径资源与地图检查通过。

逐帧输出和截图保存在运行环境的 `.delivery/navigation-motion/`。这是浏览器模拟视口验证，不代表真实手机设备认证。
