## 古村、道路参考点与上车点分开

计算锚点从附近 primary / secondary / tertiary / unclassified 道路的真实节点选择，排除高速、快速路、连接匝道、居住区小巷、停车场和私人道路作为锚点；其沿线仍可能经过尚未核验大客车条件的其他机动车道路。它只是“道路研究参考点”，不能当作上车点或精确导航终点。

龙宫在仅含主要道路的第一轮样本中离最近普通道路节点2,256米；补充原始支路后找到94米的真实节点，没有把远处主路强行当村口。其他点即使偏移很小，也可能隔河、隔墙、位于不便过街的一侧；**近距离不是可上下客或可步行的证据**。现用500米仅作为研究参考点展示限值，超限坐标置 null，不是适老步行阈值或安全标准。

所有参考点 `accessConnectionStatus='unknown'`，不画村点至参考点的直线。去返程暂以同一节点作计算锚点，不能据此认定同侧停车、过街或掉头成立。正式 BoardingPoint 与 Service 仍为空。

## 图算法、限制与缺口

`scripts/prepare-route-research.mjs` 使用真实相邻 OSM node ID 建立有向图。交叉的线段不自动成为路口；同名节点、坐标靠近和视觉交点不做连接。村落代表点不参与图边生成。每一对有序起终点单独进行 Dijkstra，不把去程坐标数组倒序充当返程。

- 处理 oneway=yes/-1/no 与明确的车型方向覆盖；无显式值时采用 motorway、roundabout 的单行默认。
- 按 motorcar → motor_vehicle → vehicle → access 的适用优先级判断通行，处理正反向访问限制；bus=yes 不会替普通车辆解除禁行。
- 有条件通行、变向单行或未知访问值保守排除，不假装已解析日期条件。
- 若遇到 restriction 关系，保守排除其参与道路，未宣称实现完整转向规划。障碍、涉水、未开放建设、停车用途服务路不参与已知受限的图边。
- 相同节点ID若坐标冲突，拒绝将其作为连接点。
- 限高、限宽、坡度、桥梁承载、转弯半径、季节封闭和所有未映射限制仍待现场及运营审核；道路分类不等于公交承载资格。
- 部分普通车研究路径涉及 residential/service 道路，逐条加注风险，不能预设公交进入古村巷道。

当前图有42,047个节点、77,220条有向边、14个弱连通分量。五个研究参考点的**20/20个有序点对**都找到连续样本道路；10对去返关系中有8对几何不同。其余孤立部分与缺失支路保持原状，没有补画连接线。完整每边原始 way ID 证据、长度、排除项和连通分量见 `data/geography/reports/route-research.json`。

`distanceMeters` 为原始相邻道路顶点的球面距离累加并取整；仅用于样本比较。所有 `estimatedDurationSeconds=null`，不通过平均速度或直线长度生成时间。路线永远 `operatingStatus='research-not-confirmed'`。

## 生成、验证与交付

```powershell
node --experimental-strip-types scripts/prepare-route-research.mjs
node --experimental-strip-types --test tests/route-research.test.ts
```

- 输出：`public/geography/route-research.json`（v2）、`access-roads.geojson`及离线审查报告。
- 类型契约：`src/geography/routeTypes.ts`。这是独立道路研究数据，未改写已核验古村代表点或正式服务数据。
- PASS：7项路线专项测试。包括单行/返程、访问优先级、条件限制/道路用途、转向限制/障碍、伪交点/冲突坐标、过远空态，以及20条路线的每一条边与原始允许方向、距离加总的复核。
- 运行时类型检查、页面浏览器验证与最终截图由主界面交付记录汇总；本文件不代替该结果。

后续现场审核至少需要村外停车空间、车道与上下客侧、过街和步行连接、道路宽度与承载、桥梁/坡度/急弯/掉头及完整的季节限制。未经确认不会开放公交乘车导航或发布运营信息。
