# 宁海五村规划环线：道路闭合复核

复核日期：2026-10-19。实际基线为 v2.2.2。本报告对应本轮增量任务阶段 A 的道路研究，不代替地图交互验收、现场踏勘或公交运营批准。

## 结论

本轮从真实有向道路样本重新比较五村环游顺序，选择：

**清潭村 → 龙宫村 → 箬岙村 → 梅枝田村 → 许家山村 → 清潭村。**

这是供地图浏览的规划环线，**非已开通公交线路，也不是车辆导航**。清潭是浏览起点，不是已核验的始发站。保留现有古村代表点和道路研究参考点，没有移动村点、补画跨地形直线或把景点当停站。

闭合路径共 3,340 条原始有向道路边、3,341 个连续顶点，全部按真实 OSM node ID 连通，首末 node ID 均为 `3680585468`，首末坐标也完全一致。最后的许家山—清潭是独立计算的 37,857 米道路段，而非数组末尾机械追加首坐标。

全环原始几何长度取整为 **143,880 米（约 143.9 公里）**，仅含道路参考点之间的样本道路，不含上下客、停车、步行接驳或村内游览距离。`durationSeconds=null`，未按平均速度推算时间。

## 顺序选择依据

复用 `scripts/prepare-route-research.mjs` 的有向图构建器，重新计算全部 20 个有序点对。固定清潭为浏览起点，枚举其他四村的 24 种排列，并在每种排列中加入独立求解的末村返回清潭段。

24 种排列均在本地保存的样本中连通。选择标准是：先比较每种完整道路环游的几何总长，再用额外重复道路长度作同长时的比较。本次选中方案恰好同时具有最短总长和最低额外重复比例。它不是对完整真实路网、所有可能绕行或车辆运营成本的全局最优承诺。

| 方案 | 完整环游样本长度 | 说明 |
| --- | ---: | --- |
| 清潭→龙宫→箬岙→梅枝田→许家山→清潭 | 143,880 米 | 本轮选中 |
| 清潭→龙宫→许家山→梅枝田→箬岙→清潭 | 150,672 米 | 原开放链顺序补上独立返回段后的比较值，未直接沿用 |

全部 24 种比较值存于 `public/geography/travel-loop.json` 的 `evidence.candidateSummaries`。有向图同时计算反向点对仅用于比较；本轮只发布以上一个方向的研究方案，不把倒序数组作为可选反向游览功能。

## 重复、折返与自交

闭合并不等于简单圆环，本轮保留并明确记录以下现象：

- 3,104 条不同的物理道路边，被遍历 3,340 次。物理边按无方向的两个真实节点 ID 判定，不靠路名或视觉距离合并。
- 236 条物理边被正反向各经过一次；额外重复距离为 **11,233 米，占完整遍历长度 7.81%**。其余约 92.19% 是首次经过的道路距离。这个比例不同于一条路径完整去返的约 50% 额外重复，未把普通往返路线重描成环线。
- 在道路参考点 `8993747818`（箬岙）、`4883732187`（许家山）、`3680585468`（清潭）有立即反向边。它们反映本地道路网络中的进入/离开支路，**并未确认大客车可在该节点掉头、停车或上下客**。
- 排除必需的最终闭合顶点后，有 236 个节点被重复经过。全部重复边、遍历次数、边索引和相反方向状态记录在 `evidence.repeatedEdges`，没有隐藏局部折返。
- 检查非相邻且不共享 node ID 的线段，严格内部投影交叉数为 **0**。共享节点和重复边单独统计；这不是对桥梁层级、立交或车辆转向的现场验证。算法不会把二维投影交叉当作可转弯路口。

选中道路包含约 56.9 公里 trunk 和约 0.79 公里 residential，另有 primary、secondary、tertiary、unclassified。道路分类不等于旅游巴士准入证据。限高、限宽、承载、坡度、急弯、转向与动态限制资料仍不完整，原始样本的“没有记录”不表示现实无限制。

道路参考点沿用既有计算结果，与古村资料代表点相距约 49—479 米。所有参考点保持 `accessConnectionStatus='unknown'`；没有绘制村点到道路的直线，也没有声称连接可步行。`BoardingPoint`、`Service` 数组仍为空，未生成运营路号、时刻、票价、ETA 或精准导航。

## 不完整数据防护与验证

`assembleCycle` 必须同时满足：每段有完整几何、每条边有原始有向证据、相邻段末/首 node ID 一致且坐标一致、最终返回起始 node ID。任一条件不满足返回 `null`，不会添加闭合线；数据不完整时 `geometry=null`、`distanceMeters=null`、`closureStatus='blocked'`。

地图端 `hasClosedTravelLoop` 再检查段顺序、首末 ID、顶点连续性和几何与分段的一致性，拒绝缺段、假直线闭合与截断导出。

运行命令：

```powershell
node --experimental-strip-types scripts/prepare-travel-loop.mjs
node --experimental-strip-types --test tests/travel-loop.test.ts
pnpm typecheck
```
