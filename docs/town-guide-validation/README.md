## 通过的交互检查

- 首次古镇地图展示独立完整环线，390 普通字号下 5 个村落按研究顺序独立编号。顺序说明明确为规划、非运营，末段独立返回清潭，不生成时间预测。
- 390 与 320 大字号下，原卡片内的新入口没有横向溢出；清单与简介可滚动，关闭和朗读按钮可到达，内容不被裁掉。
- 320×568 大字号下，相交村落触控区合并为两组，覆盖全部 5 村。可见触控区均至少 48×48，互不重叠；点击组打开已有五村顺序表，选择另一村后焦点回到可见总览按钮。
- 清潭真实资料点一击打开简介；关闭与 Escape 恢复原地图相机，焦点回到实际地图触发按钮。列表进入简介时焦点留在同一模态框内。
- Tab 在简介的交互控件中循环；手机式浏览器 Back 优先关闭简介，保持 `#/town` 与地图范围，不先跳走页面。
- 关闭简介后浏览器 Forward 回到旧同 URL 历史记录，再次打开简介，Back 仍能一次关闭，不滞留在同 token 的重复记录中。
- 快速切换古村以最后选择为准；五村的 12 条简介逐条验证名称、归属、正文与位置待核验提示，不出现虚构导航按钮。
- 拖动真实地图后进入候车再返回，恢复原相机；主动点击“查看完整环线”才重新适配全线。
- 从许家山建立龙宫研究区间、保存返程计划再返回，地图进入新区间范围；浏览其他村和景点不改变原保存计划的起终点、方向或时间戳，仍可返回完整环线。
- 无自动朗读；没有本地中文语音时显示文字降级提示，不调用远程语音服务。

对比冻结的 v2.2.2 生产构建：候车、返程、乘车码、线路、车票、帮助、异常提示 **7 个非地图页面**，逐页比较手机外框、顶部栏、标题、巴士标识、曲面区域、主按钮、下方色块与五项导航的尺寸、位置、字体、颜色和圆角，全部一致。随机巴士选型保留，不用固定全局随机数改变地图引擎行为。

## 明确标注的故障注入检查

这些用例只修改隔离测试浏览器的响应，不改变正式数据：

| 故障 | 结果 |
| --- | --- |
| WebGL 不可用，同时环线 JSON 返回 404 | 显示重试与失败信息，村落选择和真实简介仍可使用 |
| 移除真实返回段，完整 geometry 和总长置空 | 只保留已知分段，提示闭合待核验，不显示完整里程或假闭合线 |
| 真实简介的坐标置空 | 不落地图点，仍可从清单打开并明确提示位置待核验 |
| 代表图片返回 404 | 说明图片未加载，正文和关闭/朗读操作保留 |
| POI 目录为空 | 显示资料核验中，不编造景点，环线仍可浏览 |
| 两个具名测试记录使用同一测试坐标 | 聚合为一个至少 48×48 的触控入口，打开具名列表后可准确选择其中一个 |

## 执行方式

```powershell
node tests/town-guide-browser.mjs
```

环境变量 `TOWN_GUIDE_FILTER` 支持修复后的定向复测；结果按场景名合并，不把未执行项自动改成通过。`PREVIEW_URL` 可修改本地入口。非地图回归使用本轮在构建前冻结的 `.delivery/town-guide-v222-baseline`；它是忽略目录中的本地测试快照，不包含待发布版本。

最终交付前由主任务另外汇总类型检查、构建、纯函数/数据测试。真实坐标缺口、320 大字号使用聚合布局，以及尚未完成实机测试，均没有被此浏览器报告掩盖。
