## 字体与素材

压缩包只有效果图，没有字体文件或字体名称，无法确认原字体。当前使用视觉接近的本地开源替代，不声称是原字体。

- 正文和粗黑标题：[Noto Sans SC](https://github.com/notofonts/noto-cjk/blob/main/Sans/README.md)，使用 100–900 可变字重，局部标题采用 800/900。
- 书法气质字标及桌面展示文案：[霞鹜文楷 LXGW WenKai](https://github.com/lxgw/LxgwWenKai)。
- `public/fonts/` 内置 WOFF2 网页子集及两份 OFL 许可。两份字体合计约 212 KB，无运行时远程字体请求。
- 原始 TTF 在本地 `references/`，不随源码发布；可从上述字体官方仓库取得 `NotoSansSC-VF.ttf` 和 `LXGWWenKai-Regular.ttf`，放入 `references/`。`scripts/prepare-mobile-assets.py` 从手机源文件收集字符并生成 WOFF2。新增中文文案后需重跑此脚本，否则缺失字符使用系统字体回退。
- LOGO、线路、点阵、示意导览地图均以 SVG/CSS 重绘；没有使用效果图当整页背景。
- 演示 QR 仅编码 `BAIXI YUJI / UI DEMO ONLY / NOT A TRANSIT TICKET`。它不是支付凭证、车票或核验码。

素材生成脚本需要 Python 及 `fonttools`、`brotli`、`qrcode`。建议使用项目虚拟环境安装这些可选依赖，再运行 `python scripts/prepare-mobile-assets.py`。正常运行与构建直接使用已提交的字体子集，不需要执行这一步。

## 凹槽跟随导航与排版修订

按用户追加要求保留右侧导航，改为一根连续圆角长条。横向导航的上边缘 U 槽对应旋转为右侧导航朝向内容区的左边缘 U 槽。

- `src/mobile/GrooveNavigation.tsx` 使用一个连续 SVG path，四段相切的三次贝塞尔曲线形成柔和肩部与内凹轮廓；没有矩形高亮块或盖在长条上的背景色假切口。
- 同色圆形底座和实际槽口共用一份逐帧位置，480ms 平滑过渡。快速切换从当前位置转向，清理过期动画；改变尺寸立即重新计算，减少动效时直接落位。
- 圆形底座与槽口之间保留约 4–5px 的透明间隙，透出手机页面底色。选中图标独立向内容侧浮起，恢复项回落；所有点击区域与其余图标排列固定。没有导航弹跳、模糊或发光。
- 增加内容容器高度查询，站点行按实际空间分配，较矮内容区收起重复辅助说明，保持首末班信息独立。修复车票底部被挤出、字号与曲面交叉、底部装饰文字与按钮相交。
- `tests/groove-navigation.mjs` 新增逐帧同步、路径改变、图标点击区域不动、图标居中、快速转向、首尾间隙、减少动效和排版检查。
- 8 页面 × 3 字号 × 8 尺寸，192 组检查通过，其中包括用户当前内嵌预览实际尺寸 950×956。原有功能回归与布局检查仍通过。
- 记录：`docs/groove-navigation-results.json`；截图：`docs/mobile-screenshots/groove-route-390x844.png`、`groove-route-950x956.png`、`groove-scan-390.png`。

## 全局字号、返程卡与老年人模式

小 / 中 / 大分别使用统一的 90% / 100% / 118% 文字比例，所有页面、侧栏、SVG 站名与弹层共同变化；切换字号保持原有功能结构。字号保存在当前浏览器。标题区增加留白，曲面帽沿相应收紧，不挤压主要内容。

截图中的主按钮增加清晰的图标底座，返程卡突出出发时间和方向。陶赭色卡片统一 32px 圆角（窄屏 28px），顶部增加间距，让右上角弧线完整露出，避免被按钮的米白背景截断。

设置里新增独立的老年人模式，默认大字并减少动效。首页显示上车站、方向与到站时间，提供换站、乘车码、返程、求助四个按钮；每个子页面都有明确的返回首页和当前信息朗读。返程只需选时间和保存，求助直接显示可给工作人员看的乘车信息，没有未接通的电话按钮。退出模式恢复开启前字号。

设计参考 [W3C 老年用户可访问性](https://www.w3.org/WAI/older-users/) 与 [44×44 CSS px 触控目标说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)，关注明确标签、更少步骤、充足触控面积和清楚反馈，并不声称完成全面 WCAG 认证。

`tests/accessibility.mjs` 验证所有普通页面与设置中的文字逐档增大、模式/字号持久化、换站、返程保存、一键返回、退出恢复；48 组老年人页面检查主内容不溢出且触控目标至少 44×44 CSS px，96 组普通手机页面检查标题与曲面、主按钮与返程卡无交叉。结果位于 `docs/accessibility-results.json`。
