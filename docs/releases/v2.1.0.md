# 乡序 2.1.0 · 古村研究行程联动

沿用2.0.1的手机界面，接通选中古村、道路研究方案、独立返程和本地计划保存。保留原CSS、字体、SVG轮廓、右侧凹槽导航、动效、默认平面地图及老年模式结构。

## 本次交付

- 在古村页选择起点，点击原位置的“查看道路方案”，在原线路面板四个条目中选择目的村，不自动猜终点。
- 按方向读取既有道路研究数据。许家山→龙宫为41.9km道路样本，反向为58.2km；不将距离转换成公交用时，不反转一条线代替返程记录。
- 原返程面板展示起终村及车站、班次、车辆通行待核验状态，原按钮保存本地研究计划。
- 保存所选村落、起终点、研究路线ID、方向、数据版本、保存时间与研究状态；旧演示时刻保持演示属性。
- 离线、无路径、缺反向、存储失败、资料更新均有明确处理；断网不会把已存计划的来源版本覆成空值。
- 原老年模式返程和求助内容使用相同研究状态，保持四项操作与既有结构。

## 边界

这条链路是道路研究计划，不是已开通公交线路、订票服务或公开出行导航。正式上下客点、运营班次、车辆通行保证仍缺证据，村落点与研究参考点不当作车站。本轮不新增古村坐标、建筑或DEM，不开启默认立体效果，不重做桌面或老年模式入口。

本轮实际运行：35项单元/数据检查、17项链路浏览器检查、11项导航检查、11项既有UI检查及生产子路径检查通过。真机、真实公交运营和公开导航能力验证为NOT_RUN。旧版发布包保留。
