# 乡序 2.0 · 地图界面与流畅动效

本次发布将现有手机公交APP升级为“乡序 2.0”，保留右侧凹槽导航、原公交操作和独立老年人模式。

## 2.0 更新

- 品牌更新为“乡序”，沿用原字体与奶油色、青绿色、陶土色设计。
- 古镇页采用真实道路与水系铺底，悬浮村落卡、选村栏和返程入口；切换古村时地图平滑移动。
- 小／中／大字号统一放入“设置 → 文字大小”，全局生效并保存在本机。
- 页面分层进退场、凹槽与圆座连续跟随、按钮轻按反馈、弹层平滑关闭和焦点归还。
- 完成320/390宽度的大字号适配；保留减少动态效果、适老模式和地图失败时的文字操作入口。

## 验证与边界

19项单元/数据检查、11项当前UI浏览器检查和生产项目子路径检查通过。当前自动化为Edge模拟视口，非真实设备认证。

地图使用已登记的OpenStreetMap本地样本，保留ODbL署名；村落点不是正式公交站。班次、车票和二维码仍是设计演示，未接入实时公交、支付或票据核验。偏好只保存在当前浏览器。
