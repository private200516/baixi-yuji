# 乡序 2.2.1 · 主题巴士与每次启动

右上角线路标识改为用户提供的四镇主题巴士原图：前童、许家山、龙宫、力洋。每次完整打开应用时等概率随机选择一辆，当前浏览期间保持同款；一次只显示一辆。主标题改为“宁海旅游专线”，下方车型改为“XML6805JEVJ0C8”。首页和古镇等页面共享这次选择，按钮仍进入原线路内容。

启动动画现在每次打开、刷新或新标签页都完整播放，移除跳过按钮，Escape也不能提前结束。播放完毕后平滑衔接已准备好的页面；系统减少动态效果、应用安静模式及老年模式仍播放原视频，仅简化末尾过渡。内部页面切换不重复播放。加载或播放失败仍能恢复进入应用，避免停留在启动层。

其他位置保留NH品牌徽标。源码、静态Demo与SHA-256校验文件随版本提供，旧版本保留。
