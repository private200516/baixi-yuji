# 乡序 2.1.1 · 六色视觉主题

将现有界面换为用户指定的六色套色，延续原有排版、字体、凹槽导航、动效及研究行程操作。

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 海湾青 | `#087F8C` | 候车等主要信息区域、品牌图形 |
| 灯花橙 | `#F47C64` | 返程入口、老年模式重点按钮、研究路线 |
| 花田黄 | `#EBCB63` | 导航选中状态与细节点缀 |
| 石米白 | `#F5F2E9` | 页面、浮层、古村地图底色 |
| 瓦影墨 | `#24383A` | 正文、深色导航、橙色按钮文字 |
| 雾青 | `#E5EFEB` | 设置分组、辅助卡片及地图派生颜色 |

主色统一在 `src/mobile/palette.css`，同时替换活跃样式、SVG 图案及地图图层中的旧色。边线、透明浮层与水系使用这组颜色的派生色。海湾青上的小字保留纯白辅助色（约4.75:1）；灯花橙上采用不透明瓦影墨字（约4.65:1），避免沿用浅字或降低文字透明度。

地图坐标、道路研究记录、布局尺寸、导航曲线、过渡时长、字号和老年模式逻辑均保持原样。源码、静态 Demo 和 SHA-256 校验文件随版本提供，旧版本保留。
