# 乡序 2.0.1 · 古镇导航平滑切换

修复进入或离开古镇时，右侧导航条突然改变位置和高度的问题。保留候车与古镇页面各自的最终布局和全部操作逻辑。

- 导航条位置、高度、按钮间距通过480ms连续过渡，图标保持正常比例。
- 凹槽与圆形底座在同一帧更新；圆座颜色柔和过渡，不再突然换色。
- 连续快速点击会从当前状态转向，保留同一个导航组件。
- 古镇布局样式提前加载，避免首次进入时样式到达引发第二次跳位。
- 系统和应用减少动态效果时立即落位，老年人模式保持原样。

## 验证

单元与数据检查、导航逐帧浏览器专项、320/390大字号八页面回归、减少动效检查及生产子路径检查通过。导航专项覆盖手机视口、桌面缩放预览、首次进入、返回和快速中断；同时检查全局坐标连续性、凹槽同步、圆座颜色与末态对齐。可运行 `pnpm test:navigation-motion` 复验，结果写入 `.delivery/navigation-motion/`。

当前依然是手机公交界面原型；班次、票据与二维码为演示数据。
