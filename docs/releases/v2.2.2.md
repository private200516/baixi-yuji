# 乡序 2.2.2 · 手机启动兼容修复

修复慢网络下启动视频尚未加载就提前退出的问题。原版在首个视频响应延迟 3.5 秒时，会先触发 2.6 秒阈值。现在首帧可等待 10 秒，播放停滞时限为 5 秒，视频阶段可见时间总预算为 20 秒；切到后台时暂停，恢复后继续，后台时长不消耗预算。

新增移动端 MP4，将 `moov` 元数据前置，未重新编码。原视频保留，97 帧编码数据、960×960 分辨率和 4.041667 秒时长均不变。增加可见海报及明确的静音、自动播放、行内播放设置；遇到拒播、媒体错误或超时，完整播放 4.042 秒 NH 矢量动画，再进入应用。

仅启动页标题改为“宁海公交”，应用仍名为“乡序”。每次完整打开、刷新和新标签页都会播放，内部切页不重播；不提供跳过。正常播放后用 640 毫秒平滑过渡，减少动态效果或老年模式只简化末尾过渡。

本地验证：核心启动检查 17/17、手机仿真专项 10/10、单元测试 35/35 通过，构建通过。正式构建在项目子路径下通过 8 个页面、地图与字体资源，以及路线选择、返程、保存和恢复检查。手机检查使用 Edge / Chromium 的 iPhone 13、Pixel 7 仿真，后台状态通过 API 模拟，尚未完成真实手机或 Safari 验收。
