# 乡序 2.3.0 · 旅游环线与景点简介

在原手机 UI 内接入完整规划环线、村落编号、景点资料点和简介弹层，保留 NH 品牌、主题巴士、启动动画、原配色字体及右侧凹槽导航。首次进入古镇且没有恢复中的任务时显示全线；顶部可随时查看完整环线。当前研究区间与环线独立显示，关闭简介和跨页面返回保留地图视角。

环线为清潭→龙宫→箬岙→梅枝田→许家山→清潭，沿有来源的有向道路样本闭合约 143.9 公里，包含局部折返。它是道路规划研究，不是已开通公交，不承诺车辆通行、车站、班次、时长或票价。

五村共 12 条有来源的景点简介，其中 3 条具备公开资料坐标；其余 9 条通过文字清单阅读。许家山、箬岙尚无可落图景点坐标，没有完成“每村均有可定位景点”或“单村多个真实景点同屏”的资料验收。资料点不等于建筑入口或开放许可；照片尚无可确认复用来源，因此不展示。

单点点击打开既有样式简介面板，支持明确关闭、浏览器返回、键盘焦点循环和主动本地中文朗读。密集点按触控范围聚合，不移动真实坐标；没有 WebGL 时可继续使用文字清单。浏览景点不覆盖保存的道路研究计划。

本地增量验证记录：53 项单元测试、16 个浏览器场景、5 个隔离地图场景、6 项生产子路径检查通过，类型检查及构建通过。使用 Microsoft Edge / Chromium 手机视口仿真；iOS、Android、微信实机和真实语音设备验收仍为 NOT_RUN。详细范围、截图及资料缺口见[增量验收](https://github.com/private200516/baixi-yuji/blob/v2.3.0/docs/town-guide-validation.md)。
