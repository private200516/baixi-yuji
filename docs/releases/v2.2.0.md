# 乡序 2.2.0 · NH 徽标与启动动画

采用用户提供的 NH 圆形徽标，替换首页、古镇页、车票、老年模式、品牌展示页和浏览器图标。透明 SVG 保留原徽标结构，以海湾青和灯花橙融入当前六色主题。

首次启动播放用户提供的约4秒原始视频，最后一帧通过640ms交叉淡入衔接已准备好的首页。启动时可点击“跳过动画”或按 Escape；同一标签页会话内刷新和导航不重播。直接打开古镇等页面链接时保留原目的页。

开启系统或应用减少动态效果、老年模式时直接进入应用，不下载启动视频。视频加载失败、无法自动播放或长时间没有进度时，短暂显示静态徽标后进入应用。启动期间底层控件不可误触，结束后焦点回到页面内容。

延续原布局、字体、地图、右侧凹槽导航及行程操作。通过类型检查、35项单元测试、15项启动专项浏览器检查和生产子路径全流程检查。源码、静态 Demo 与 SHA-256 校验文件随版本提供，旧版本保留。
