# 乡序 · 古镇地图场景

日期：2026-10-09。

## 当前范围

用户最新提供古镇页参考图，要求恢复原动画、将地区界面改成参考图，并保持视觉过渡流畅。此要求接续此前“保留原UI逻辑”的约束：仅古镇页允许调整为地图铺底与悬浮布局，其余页面、主导航项目和原业务回调保留。

- `TownScene.tsx`：暖米白地图铺底、导览标题卡、线路标识、字号控件、村落卡片、选村胶囊、陶土色返程入口。
- `TransitApp.tsx`：只有古镇内容使用新场景。共享五项 `GrooveNavigation` 保留在条件分支外，保持同一个组件实例。
- `town-scene.css`：场景局部样式，使用原字体、配色和圆角语言；按实际容器高度适配短屏。
- 地图 `presentation="scene"` 使用同一份已登记的真实地理样本，隐藏卡片地图内部工具与县界装饰，保留来源署名。历史卡片模式继续兼容。
- 村落点与公交站严格区分；没有将旧演示站点绑定为真实地图点，没有虚构地形、水路或建筑。

## 动效和操作

选村使用同一MapLibre实例，以720ms缓入缓出移动真实相机。标题与卡片轻移淡入，村落信息切换使用短淡入。浮层布局由ResizeObserver测量，选中点停在控件之间的空白区域。

原导航480ms凹槽与圆座同步动画保留；修复窄屏页面变换使导航条尺寸改变时，ResizeObserver直接跳终点的问题，改为从当前圆座位置继续过渡。每个图标仍由自己的固定按钮控制，没有用整体图标平移模拟导航。

字号仍影响全部页面，原设置和老年四任务模式保持。应用“减少动态效果”、系统减弱动效及老年模式仍被尊重；没有重置本机偏好。

“查看公交线路”进入原线路页；返程入口进入原返程页；地图选点与文字选村更新同一村落状态。失败提示与文字选择不依赖WebGL渲染成功。
